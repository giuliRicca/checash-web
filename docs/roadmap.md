# Che Cash Roadmap

- Auth, accounts, categories, income/expense transactions, transfers, chat capture, dashboard summaries.
- Exchange-rate cache from backend provider.

- Add refresh-token/session strategy and secure token storage.
- Add end-to-end coverage for auth, account creation, chat confirmation, and activity pagination.
- Define deployment, backups, monitoring, and rate-provider outage alerts.
